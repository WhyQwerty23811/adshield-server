      📱 Connect to Your Private DNS

      Connect your phone and devices without installing any battery-draining VPN apps:

      Your Private DNS Hostname:

      🤖 Android (Version 9 to 15+)

      1. Open Settings → Network & Internet (or Connections).
      2. Tap Private DNS.
      3. Select Private DNS provider hostname.
      4. Paste: dns.example.com and tap Save.
      ✨ Android will instantly connect over encrypted DoT (Port 853). Zero battery drain!

      🍎 iOS / iPadOS / macOS

      Configure DNS-over-HTTPS (DoH) via an encrypted mobile profile or in browser settings:

      DoH URL: https://dns.example.com/dns-query

      💻 Windows 11

      1. Open Settings → Network & Internet → Wi-Fi / Ethernet.
      2. Under DNS server assignment, click Edit.
      3. Select Manual → Enable IPv4 → Enter your VPS IP.
      4. Set DNS encryption to Encrypted only (DNS over HTTPS) with template https://dns.example.com/dns-query.
